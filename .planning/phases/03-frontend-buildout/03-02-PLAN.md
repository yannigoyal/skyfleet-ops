<objective>
Prove the entire Phase 3 client architecture end to end on one path: the operator launches
a mission from the dispatch bar and watches the header's remaining energy budget drop.

That single path touches every layer this phase owns — the type layer (`types/fleet.ts`),
the state layer (`FleetOpsProvider`: poll, accumulate, refetch), the write path
(`DispatchBar` → `POST /api/fleet/missions`), the read path (`Header` ← live
`remaining_kwh`), and the mount point (`page.tsx`). If the `FleetOpsProvider` shape is
wrong, this plan finds out after one commit rather than after five panels are already
built on top of it.

Purpose: `FleetOpsProvider` is rated **costly** to reverse (D-01) — seven components will
consume it by the end of the phase. Proving it against a real launch/refetch round trip
before any of those consumers exist is the whole point of leading with it.
Output: a working, committed vertical slice — launch a mission, see the budget move — plus
the accumulated-mission merge logic every later panel reads from.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → backend REST API (`/api/*`) | Unauthenticated same-origin calls; the backend is the only validation authority |
| Operator free-text input (`zone`) → DOM and → backend | Untrusted operator-authored string crosses into both render and persistence |
| Backend error body → DOM | The `detail.reason` string is rendered verbatim in the dispatch bar per D-14 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Tampering | `DispatchBar` zone field rendered into the DOM and echoed back from mission responses | medium | mitigate | Render every operator- and backend-originated string as a plain JSX text child only. React escapes text nodes by default; no raw-HTML injection prop is used anywhere in `DispatchBar.tsx`, and the negative gate in the acceptance criteria pins that. |
